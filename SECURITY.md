# Security policy

Kamikaze Hero is an offline single-player game, so its attack surface is
small. It does talk to one online service (Unity Ads), and the repository may
contain configuration that should not be public.

## Supported versions

Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please do **not** open a public issue for security problems, including
leaked credentials or keys you spot in the code or git history.

Instead, use GitHub's
[private vulnerability reporting](https://github.com/Dehdar/Kamikaze-Hero/security/advisories/new)
for this repository. Include what you found, where (file and commit), and how
it could be misused.

You can expect a first response within two weeks. This is a hobby project, so
fixes are made on a best-effort basis.
