## Generated assets

Every asset in the game except the music and the font is generated by the
Python scripts in `Tools/AssetGenerators/`:

| Script | Generates |
| --- | --- |
| `particle_textures.py` | Particle textures for fire, smoke, sparks and debris |
| `sound_effects.py` | Sound effects (gun, engines, missiles, explosions) |
| `models.py` with `unity_mesh.py` | The 3D models in `Assets/Models` |
| `pictures.py` | Sky backgrounds, app icon, Kamikaze button and US flag texture |

These generated assets are part of this project and are covered by its MIT
license. Re-run the scripts to tweak or regenerate them. The design of the US
flag itself is in the public domain.

## A note on git history

Earlier versions of the game used third-party assets that have since been
removed (a paid Unity Asset Store effects pack, a demo font, and downloaded
models, photos and sounds). Those files still exist in older commits of this
repository. They are not part of the current project and are not covered by
